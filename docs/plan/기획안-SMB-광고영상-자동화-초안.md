# Meta 해커톤 기획안 – SMB 광고 영상 자동화 (초안)

Oct 23, 2026 · @김유빈

## 한 줄 요약

(가칭) AdLoom은 소상공인이 폰으로 찍은 10\~30초 영상 한 개를 받아 9:16·4:5·1:1 광고 영상 3종과 카피를 만들고, Meta 광고 계정에 "일시중지" 상태로 올려 주는 도구입니다. 사장님은 미리보기를 보고 승인 한 번만 누르면 됩니다.

**핵심 설계 선택: 영상을 생성하지 않고, 사장님의 실제 영상을 광고 규격으로 재구성합니다.** Meta Model API에는 영상 생성 모델이 없고, 영상은 입력으로만 쓰입니다([모델 목록](https://dev.meta.ai/docs/models)). 이 제약을 약점이 아니라 설계 원칙으로 바꿉니다. 실제 제품·시공 영상이어야 소상공인 광고에 신뢰가 생기고, 생성 영상에서 흔한 허위·과장 표현 위험도 줄어듭니다.

심사 기준과의 대응 (개인 트랙: 창의성 · 기술적 야심 · 동작 여부, [행사 페이지](https://cerebralvalley.ai/e/meta-ai-developer-hackathon)):

- **창의성:** "AI가 만든 광고"가 아니라 "사장님 영상을 광고로 바꿔 주는 편집자"라는 포지셔닝.
- **기술적 야심:** Muse Spark(영상·음성 이해), SAM 3.1(영상 속 제품 추적), Muse Image(썸네일·배경), Marketing API(게시)를 한 파이프라인으로 연결.
- **동작 여부:** 데모 마지막 장면에서 실제 Meta 광고 계정에 광고가 생성된 화면을 보여 줌.
- **테마:** Build for Your World — 소상공인 현장에서 쓰는 도메인 문제.

## 문제와 타깃

소상공인은 폰으로 찍은 좋은 영상은 있어도 그걸 Meta 광고로 내보내는 단계에서 막히는 경우가 많습니다. 아래는 조사 전 **가정**이며, 수치는 아직 근거가 없어 쓰지 않았습니다.

| 막히는 지점 | 사장님이 겪는 일 | AdLoom이 대신하는 일 |
| --- | --- | --- |
| 편집 | 세로·정방형 등 규격별로 자르고 다시 인코딩 | 제품을 따라가며 3가지 비율로 자동 재구성 |
| 카피 | "뭐라고 써야 하지" — 훅·자막·CTA | 영상을 보고 훅 후보·자막·CTA를 만들고 사장님 말투로 다듬기 |
| 썸네일·엔드카드 | 디자인 도구를 따로 배워야 함 | Muse Image로 대표 이미지와 마지막 카드 생성 |
| 광고 세팅 | Ads Manager의 캠페인·광고 세트·광고 계층을 직접 설정 | 지역·예산만 묻고 계층을 자동 생성 (일시중지) |
| 정책 | 과장·금지 표현으로 거부당한 뒤에야 알음 | 게시 전 문구·영상 사전 점검 |

**처음 겨냥할 사용자:** 제품이나 시공 결과를 폰으로 찍을 수 있는 1\~5인 점포(시공·수리·뷰티·음식·소품 등). 데모는 그중 한 업종의 실제 영상 1\~2건으로 합니다. 실제 점포 영상을 쓰면 Build for Your World 테마에 더 설득력이 생깁니다.

## 서비스 흐름

&#91;embedded content: AdLoom 서비스 흐름 · 6단계, 마지막만 사람이 승인\]

1\~5단계는 자동으로 돌아가고, 광고가 실제로 나가기 전 마지막 한 번은 반드시 사장님이 승인합니다. Marketing API는 캠페인·광고 세트·광고를 일시중지(PAUSED) 상태로 만들 수 있고([가이드](https://developers.facebook.com/docs/marketing-api/guides/videoads/)), 소재에는 페이지 ID와 썸네일 이미지가 필요하므로 썸네일을 Muse Image로 만드는 단계가 흐름에 들어갑니다. 이 서비스의 범위는 자동 게시가 아니라 "승인만 남은 상태"까지입니다.

## Meta 모델 활용

4개 모델이 파이프라인의 서로 다른 단계를 맡습니다. 아래 사양은 [Meta Model API 모델 문서](https://dev.meta.ai/docs/models)에서 확인한 내용입니다.

| 모델 | 쓰는 곳 | 문서상 사양·제약 |
| --- | --- | --- |
| Muse Spark 1.3 | 영상·음성을 보고 제품, 핵심 장면, 훅, 카피, CTA, 정책 위험 문구를 JSON으로 출력 | 텍스트·이미지·영상·음성·PDF 입력, 텍스트 출력. 음성 지원은 완전하지 않아 음성은 1.2를 권장 |
| SAM 3.1 | 텍스트로 지정한 제품을 영상 전체에서 마스크로 추적 → 재구성 기준점 | 텍스트 프롬프트 + 이미지·영상 입력, 박스와 마스크 출력, 영상은 프레임 간 추적 |
| Muse Image | 썸네일, 엔드카드, 배경 생성·편집 | 텍스트·이미지 입력, 이미지 출력. 생성·편집 엔드포인트 제공 |
| Muse Voice Transcribe | 사장님 음성 설명과 영상 속 말을 자막용 텍스트로 변환 | 음성→텍스트만 지원(음성 합성 없음), 시간당 $0.18 |

쓰지 않는 것: **Muse Wonder**는 미리보기 단계이고 문서에 "한국에서는 사용 불가"로 적혀 있어 제외했습니다.

**확인 필요 (문서에 없거나 모호한 것)**

- 영상 입력의 길이·용량 한도는 적혀 있지 않습니다. 30초 이하 폰 영상으로 먼저 테스트해야 합니다.
- 한국 내 계정·API 사용 가능 여부는 문서에 언급이 없습니다. 해커톤 승인은 받았지만 API 키 발급과 호출이 실제로 되는지 킥오프(10/26) 직후 첫 호출로 확인해야 합니다.
- SAM 3.1 영상 추적의 요청 형식은 Media segmentation 가이드에 있어 아직 읽지 못했습니다.
- Muse Spark의 Contributor 모드는 더 싼 대신 내용이 학습에 쓰입니다. 고객 영상이 들어가므로 Standard 모드만 쓰는 것이 원칙입니다.
- 영상 생성 모델이 없으므로 움직임은 실제 영상 구간과 정지 이미지의 줌·패닝으로 만듭니다.

## 데모 시나리오

심사는 영상으로 하므로(제출 형식은 킥오프 후 공지, 확인 필요) "대본"이 곧 제품입니다. 실제 점포의 영상 한 개를 맨 처음부터 끝까지 한 번에 보여 주는 구성이 가장 안정적입니다.

1. **문제 제시:** 사장님이 폰으로 찍은 20초 내외 시공·제품 영상. "좋은 영상은 있는데 광고로 올리는 법을 몰라 그대로 묵혀 둡니다."
2. **입력:** 영상 업로드 + 음성으로 한 마디("우리 동네 수도 수리인데 예약 좋겠어요") + 지역·예산.
3. **이해 화면:** Muse Spark가 뽑은 제품명·훅 후보 3개·카피. 과장 문구("100% 보장" 같은 표현)가 정책 점검에서 표시되고 순화된 문장으로 바뀝니다.
4. **추적 화면 (시각적 하이라이트):** SAM 3.1 마스크가 영상 속 제품을 따라가고, 9:16·4:5·1:1 크롭 프레임이 같은 제품을 중심에 둔 채 나란히 보입니다.
5. **완성:** 3개 비율 영상과 훅 A/B 비교, 추천 1개.
6. **승인·게시:** 승인 버튼 → 실제 Meta Ads Manager 화면에 일시중지 상태의 광고가 생긴 것을 보여 줍니다. "동작 여부" 심사 기준에 정확히 대응하는 장면입니다.
7. **수정 (시간이 남으면):** "가격 빼 주세요"라고 말하면 자막이 바뀌어 다시 렌더됩니다.

데모의 가장 큰 위험은 6번입니다. 광고 계정·페이지 권한이 여기서 막히면 시연을 못 하므로, 테스트용 광고 계정과 페이지를 킥오프 전후로 미리 준비하고, 실패해도 API 응답 화면을 보여 줄 수 있도록 녹화해 둡니다.

## 차별화

**겹치는 부분이 있습니다.** Meta 자체 Advantage+ Creative도 사용자의 기존 영상·이미지에 AI 더빙, 배경, 음악을 붙이고 바로 게시합니다. 심사에서 같은 질문이 나올 수 있어 아래처럼 선을 그었습니다. 도구 설명은 제3자 비교 글([Rework](https://resources.rework.com/tools/ai-tools/best-ai-tools-for-facebook-instagram-ads-2026))과 [Adweek 기사(2025-06-17)](https://www.adweek.com/brand-marketing/metas-advantage-adds-gen-ai-tools-for-advertisers-and-agencies/)에 근거한 것이고, 제품별 최신 기능은 직접 써 보고 다시 확인해야 합니다.

| 기존 도구 | 하는 일 | AdLoom과의 차이 |
| --- | --- | --- |
| Meta Advantage+ Creative | 기존 영상에 AI 더빙·배경·음악을 붙여 Ads Manager에서 게시 | 이미 Ads Manager를 쓸 줄 아는 광고주 전제. AdLoom은 영상 하나에서 캠페인 뼈대까지 만들어 주는 "처음부터 끝까지" 흐름 |
| Creatify, Arcads | 제품 URL·스크립트로 AI 배우 UGC형 영상 생성 | 영상을 생성합니다. AdLoom은 사장님의 실제 영상을 쓰고 생성 영상의 허위·과장 위험이 없음 |
| Typeface(Pencil) | 브랜드 자산으로 영상·이미지 광고 생성, 성과 예측 | 대형 브랜드 대상. AdLoom은 브랜드 자산이 없는 1\~5인 점포 대상 |
| Canva Magic Media | 텍스트로 이미지·영상 생성, 편집 가능한 디자인 | Meta로 보내지는 않음. AdLoom은 게시 단계까지 포함 |

AdLoom에서 진짜 차별이 되는 것은 세 가지입니다.

- **영상 속 제품을 추적해 규격별로 다시 구성**하는 기능(SAM 3.1). 단순 중앙 크롭과 달리 제품이 화면 밖으로 잘리지 않습니다.
- **정책 사전 점검**과 문구 순화를 생성 전에 해서 광고 거부 리스크를 줄임.
- **사장님 말투와 실제 영상을 보존**하는 편집자 포지셔닝.

다만 숫자로 효과를 주장할 근거(광고 성과 등)는 아직 없습니다. 데모에서는 "만드는 시간"과 "작동하는 흐름"만 보여 주고 성과 수치는 약속하지 않습니다.

## 기술 구조와 MVP 범위, 일정

제출 마감은 **11/5(목) 11:00 KST**(11/4 21:00 ET)이고, 킥오프는 10/26입니다. 킷오프 전에 Meta API가 필요 없는 부분부터 만드는 것이 핵심입니다.

**구조 (제안):** 웹 폼(영상 업로드·미리보기·승인) + 백엔드 워커. 워커가 Meta Model API(Spark·SAM·Image·Voice)를 호출하고, ffmpeg로 렌더하고, 승인 후 Marketing API를 호출합니다. 렌더는 결정론적이라 같은 입력이면 같은 영상이 나옵니다.

**MVP에 포함:**

- 영상 1개 입력 → 3개 비율 영상 + 훅 A/B + 카피
- 정책 사전 점검 표시와 문구 순화
- 테스트 광고 계정에 일시중지 상태의 광고 생성

**MVP에서 제외:** 광고 자동 활성화, 결제, 다중 계정, 성과 분석, 영상 생성.

**일정 (오늘 10/23 기준):**

1. **10/23\~25 (킷오프 전):** 데모 대상 영상 확보, 테스트용 Meta 앱·광고 계정·페이지 준비, ffmpeg 렌더(훅 문구·자막·엔드카드)를 모의 데이터로 먼저 구현.
2. **10/26\~27 (킷오프):** API 키 발급과 호출 확인(Spark 영상 입력, SAM 영상 추적, Muse Image), Official Rules에서 허용 모델·기존 코드 규정 확인.
3. **10/28\~30:** SAM 추적 → 3개 비율 재구성, Spark 출력 JSON 스키마 확정. 10/30은 의성군·경기스포츠·KOBC 마감일입니다.
4. **10/31\~11/2:** Marketing API 게시(PAUSED) 연결. 10/31\~11/1 푸드테크 포항, 11/2 OIBC와 겹치므로 작업량을 가볍게 잡습니다.
5. **11/3:** 데모 영상 촬영·편집.
6. **11/4:** 제출물 정리와 예비일. 다음 날 11/5는 스페이스 서류 마감(18:00)이 같은 날이라 미루지 않습니다.

## 리스크와 확인 필요

가장 크게 흔들릴 수 있는 것은 세 가지입니다: 한국에서 Meta API가 실제로 호출되는지, Marketing API 권한과 테스트 계정을 데모 전에 준비할 수 있는지, 심사에서 "Meta 기능과 같은 것 아니냐"는 질문에 답할 수 있는지.

- [ ] Official Rules(10/26 전 공개): 허용 모델, 기존 코드 사용, 제출물 형식, 트랙·팀 규정 확인
- [ ] 한국에서 Meta Model API 키 발급·호출 (문서에 지역 언급 없음; Muse Wonder는 한국 불가로 명시)
- [ ] SAM 3.1 영상 입력 한도와 요청 형식 (Media segmentation 가이드)
- [ ] Muse Spark 영상 입력 길이·용량 한도 테스트
- [ ] Marketing API: 앱 권한(`ads_management`, `pages_read_engagement`), 테스트 광고 계정·페이지, 캠페인 필수 필드 `special_ad_categories` 처리
- [ ] Meta 광고 영상 규격(비율·길이·용량): Marketing API 가이드에는 없고 Advertiser Help Center에서 확인
- [ ] "Advantage+ Creative와 무엇이 다른가" 답변 준비 (차별화 섹션의 세 가지)
- [ ] 데모 영상은 본인 소유 또는 동의를 받은 것만 사용, Spark는 Standard 모드만
- [ ] 개인(Indie) 트랙으로 진행 확정
- [ ] 일정 충돌: 10/24 Bloom, 10/31\~11/1 푸드테크 포항, 11/2 OIBC, 11/5 스페이스 마감, 11/7 PQC 예선
